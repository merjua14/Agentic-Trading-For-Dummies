Agentic Trading for Dummies is up.

Paper-first Liquid tutorial (simulated, not real money). Paste a rulebook (the written rules). A runner (a small Python clock) follows them. Risk starts at 1.5%. Soft halt on. Hard halt on. The runner refuses --live, so it cannot flip to real money by accident.

No return promises. Read the disclaimer. Start on paper.
